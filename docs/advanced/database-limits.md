# 数据库设计限制

截至本文档修订时，服务端可支持从 SQLite 和 MySQL 中任选其一作为数据库引擎。然而，由于不同的数据库引擎在许多方面存在行为差异，服务端无法保证高度依赖数据库具体行为的功能在所有的数据库引擎上均表现一致。例如，在 SQLite 和 MySQL 中，字符串比较的大小写敏感性可能有所不同；在 MySQL 中，这一行为还会因所使用的排序规则（collation）而异。

服务端支持的部分功能在接受参数长度上的限制与数据库的结构有关，因此在对其进行修改前请务必确认数据库的当前结构是否容许修改后的全部合法输入。例如，文件名和目录名的最大长度均为 255 字符，其对应的数据表的列接受的最大数据长度同样为 255 字符。受这一限制的影响，搜素功能接受的输入的最大长度亦被设置为了 255 字符。
