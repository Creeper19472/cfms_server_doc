# CFMS 不是什么

## CFMS 不是文件加密工具

CFMS 是针对保密信息的管理和传递而设计的，它解决的是如何通过妥当的权限管理实现用户对保密信息的受控访问，以及如何确保保密信息在通过互联网进行传输时的安全。

事实上，任何上传到 CFMS 系统的文件都将在服务器以明文状态存储；而 CFMS 无意，也不能控制用户在取得解密后的文件后的行为（尽管文件将在传输过程中实时加密，而客户端在取得文件的所有部分前，已下载的部分仍将保持加密状态）。这意味着，系统管理员不应期望 CFMS 能够确保存储在服务器上的信息的安全——那仍是系统管理员的工作；也不应期望 CFMS 能够阻止用户在取得保密信息后的不当行为。
