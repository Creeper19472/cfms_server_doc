# 功能概览

服务端为实现其设计目标而提供了多种功能，按照应用方向的不同，以如下几个分类进行组织。

## 文档管理类

### 目录与文档读写

可以创建、移动、删除、恢复、永久清除和重命名目录与文档，以及获取它们的统计信息。处于活动状态的文档和目录在同一目录内共用一个名称空间，且名称始终不得重复。

删除操作通常只会将项目标记为已删除，并立即释放其名称；有相应权限的用户可以查看被删除的项目，并在解决名称冲突后将其恢复。删除目录时，服务端会逐项检查权限，因部分项目无权删除而未能完整完成操作时将返回部分成功结果。

### 文件传输

上传和下载使用独立的文件传输任务。任务具有待处理、传输中、已完成、已取消和已过期等状态，并受开始期限、硬性期限及空闲超时约束。上传和下载均可协商分块大小；带有 SHA-256 摘要的非空上传，以及仍在有效期内的下载，可以从已经完整保存的分块处恢复。

服务端对下载分块逐块加密，并仅在全部分块传输完毕后发送解密密钥。进入锁定模式或文件失去最后一个活动引用时，尚未完成的相关传输任务将被取消。更完整的行为请参阅[文档管理与文件传输](document-management.md)。

### 修订版本管理

文档的历史版本以[修订版本](revisions.md)的形式组织。一个修订版本对应一个物理文件，而一个物理文件一旦上传完成便不能再被修改。可以创建、查看和删除文档的修订版本，创建修订版本时可从过去（而并非必须是最新）的某个修订版本分叉。

可以指定某个修订版本作为文档的当前修订版本。修订版本列表使用游标分页。

### 搜索、元数据与去重

持有 `search` 权限的用户可以根据名称执行不区分大小写的字面量模糊搜索。结果会先依据对象读取权限过滤，再按稳定顺序以不透明游标分页。

文档可以记录大小、最后修改时间和标签等元数据。对于带有 SHA-256 摘要的非空上传，内置扩展会在响应上传成功后异步查找重复的物理文件，并在不改变文档与修订版本引用语义的前提下回收冗余副本。

## 用户账户类

### 用户管理

持有合适权限的管理员可以创建、编辑和删除用户，为用户重设密码，调整用户组和直接权限，封禁或解除封禁用户，以及查看用户属性、账户状态、状态说明和头像。指定用户权限、用户组和封禁范围时，可以一并设置生效的起止时间。

可以启用用户的二步验证，以 TOTP 作为验证方法，并可以查询或由获授权的管理员禁用二步验证。服务端还可通过可选扩展接入 OpenID Connect 单点登录，并选择是否自动创建本地账户。

### 用户组管理

可以创建、删除和重命名用户组，指定用户组的显示名称，或为用户组指定权限。指定用户组权限时，可以一并设置权限的起止时间。

## 访问控制类

### 对象访问控制

可以为目录或文档指定[访问规则](object-access-control.md#access-rules)，也可同时为特定的用户或用户组[授予访问权限](object-access-control.md#granting-permissions)，粒度细化至四种操作类型（读取、写入、移动和管理）。为用户和用户组授予访问权限时，可以指定授权的起止时间。

在启用递归检查且对象允许继承的情况下，服务端会继续检查其父目录。也可以在全局或特定对象范围内阻止用户执行读取、写入或移动操作。

### 锁定模式

可以使服务端进入[锁定模式](lockdown.md)，以立即阻断无豁免权限的用户的访问尝试。锁定状态和理由会持久保存在数据库中；可选的暴力破解检测扩展也可以依据一段时间内的身份验证失败自动触发锁定。

## 安全与流量控制类

服务端支持密码策略、Argon2id 密码散列、TOTP、mTLS、请求时间戳与随机数重放保护、身份验证节流、IP 网段封禁和活动锁定管理。相关行为请参阅[身份验证与安全管理](security-controls.md)。

硬性准入上限会限制单进程的连接、逻辑流和并发请求数量；[请求速率控制](rate-limiting.md)则分别按来源 IP 和已认证账户维护令牌桶，并允许为成本不同的请求指定不同权重。文档创建和下载另有独立的自适应风险控制策略。

## 审计类

可以通过游标分页查询审计日志，以了解用户的使用行为。锁定、身份验证安全管理和自动安全措施也会记录相应的审计信息。

## 密钥管理类

[可以列出、上传、读取和删除用户特异的密钥。](keyrings.md)这些密钥通常被客户端用来加密本地的敏感信息。可以指定某一密钥为用户的偏好文件密钥，以在用户成功登录时默认发送给客户端。

## 扩展与运维类

服务端通过具有版本和兼容性声明的[扩展清单](../extensions.md)发现扩展，并按配置的标识符加载它们。内置扩展始终启用，OpenID Connect 单点登录和自动暴力破解锁定则为可选扩展。

随项目提供的[维护命令](../maintenance.md)可以更新用户密码、补充配置机密、同步配置范本，以及导出、查看和导入加密备份。发布包不包含部署实例的配置、数据库、证书、凭据和其他可变状态，升级时需分别保留并迁移这些数据。
